# Flight Ops: MAVLink Telemetry Analyzer
Automated MAVLink telemetry analysis tool for autonomous agricultural flight operations

*[Read this in Portuguese / Leia em Português](README.pt-br.md)*

## 📌 Overview
This repository contains a proprietary Python-based tool designed for **Flight Operations Monitoring and Post-Flight Analysis**. It extracts, parses, and visualizes raw MAVLink telemetry data (`.tlog` files) generated by QGroundControl and ArduPilot SITL.

In large-scale autonomous agricultural aviation, relying solely on graphical interfaces can delay critical diagnostics. This script automates the analysis of essential flight parameters—such as mission altitude adherence and battery voltage drops—ensuring rapid, precise troubleshooting and compliance with safety standards during field operations.

## ⚙️ Features
*   **Native MAVLink Parsing:** Utilizes the `pymavlink` library to read `.tlog` files directly from Ground Control Stations.
*   **Targeted Data Extraction:** Isolates mission-critical packets, including `GLOBAL_POSITION_INT` (Altitude, Position, Heading) and `BATTERY_STATUS` (Power management and voltage drops).
*   **Automated Plotting:** Employs `matplotlib` and `pandas` to generate performance graphs, assisting Flight Dispatchers and Operators in decision-making.

## 🛠️ Prerequisites
*   Python 3.8+
*   QGroundControl (for `.tlog` generation)
*   ArduPilot SITL (Software In The Loop) for flight simulation
